# token-spend

Claude Code mod: shows `Session £x (tokens) · Today £y (tokens)` in the status line and adds a `/token-spend` dashboard. Priced at API list rates in GBP. On Windows it can also write totals to a OneDrive folder.

## Install

At the prompt of a terminal session:

    /plugin install token-spend --marketplace <owner>/<repo>

Desktop app: click + next to the prompt box, then Plugins, Add marketplace with `<owner>/<repo>`, then Add plugin. Choose the user scope so every session loads it.
